进阶
==========

本章在 :doc:`/tutorial/getting-started/index` 的基础上，继续沿用同一个
工作流示例，介绍如何**构建更复杂的工作流树结构与依赖关系**：先扩展
工作流的结构与参数，再逐步加入触发器、完成触发器、事件与标尺这几类
任务间依赖。

每节介绍一个新概念，建议按顺序完成各节练习，每一节都以前一节的示例
为基础。循环、限额、时间依赖与运行控制等主题见下一章
:doc:`/tutorial/advanced-topics/index` 。

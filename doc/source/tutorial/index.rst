Takler 教程
==================================

本教程的目的是通过一个简单的示例介绍如何使用 takler 在 Linux 环境中运行由 Shell 脚本任务构成的工作流。

每章节介绍一个新概念，并提供一系列练习。

.. note::

    本教程使用一台普通 Linux 服务器，不依赖任何特定 HPC 系统或账户。
    如果你在 HPC 环境（如通过 ``module`` 加载预安装环境、离线安装）中使用 Takler，
    请参考 :doc:`hpc-appendix`。

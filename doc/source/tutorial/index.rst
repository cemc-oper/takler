Takler 教程
==================================

本教程的目的是通过一个简单的示例介绍如何使用 takler 在 Linux 环境中运行由 Shell 脚本任务构成的工作流。

每章节介绍一个新概念，并提供一系列练习。

.. note::

    本教程以中国气象局国家级气象超算子系统3 (CMA-HPC2023-SC3) 为例说明如何在 HPC 环境中使用 Takler。
    相关代码也同样适用于其他 Linux 服务器。

.. note::

    本教程使用 CMA-HPC2023-SC3 上的 wangdp 个人账户。

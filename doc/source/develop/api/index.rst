API 文档
==================================

``takler.protocol`` 与 ``takler.exceptions`` 是公开接口，每页用 autosummary 显式列出收录对
象； ``takler.server`` 、 ``takler.logging`` 与 ``takler.tui`` 是内
部实现，按模块粗粒度收录，接口稳定性弱于前四者。
